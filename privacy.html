ARCH Backup — Privacy Policy

Effective: October 11, 2026

What the app accesses

ARCH Backup uses the Google Drive API with the drive.file scope only. It can access only the files it creates itself: encrypted backup archives stored in a single folder in the operator's own Google Drive. It does not access any other Drive content, contacts, email, or profile data.

How the data is used

The only purpose is to store and rotate encrypted backups of the operator's own systems. Archives are encrypted on the operator's computer before upload, so their contents cannot be read by Google or by anyone without the operator's private key.

Sharing

No data is sold, shared, transferred to third parties, or used for advertising or AI model training.

Google API Services User Data Policy

ARCH Backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Old backup archives are deleted automatically on a rolling schedule. Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Open an issue at github.com/arch-ops-mia/arch-ops-mia.github.io/issues.
